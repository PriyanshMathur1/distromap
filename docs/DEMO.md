# DistroMap: 45-second demo

Open index.html. Nothing is selected yet; the empty state explains the tool.

**0 to 10s.** Say: "Most Indian consumer startups buy installs. The cheaper question is which apps their users already open. DistroMap answers that for 80 Indian surfaces."

Click the preset **Urban salaried investor 25-40**.

**10 to 25s.** Point at the list. Say: "Every surface gets a fit score: how many of my six tags it matches, times its reach band, times how easy the easiest way in is. Livemint and Groww at the top, not PhonePe, because a 50M-user app with a mini-app store is hard to enter and mostly the wrong audience."

Click **Why** on the top row. Say: "Nothing is hidden. Matched tags, missed tags, the reach band and whether I trust it, every integration type with its ease, and the actual way in: a calculator the Mint Money desk can link from stories. That sentence is the product."

**25 to 35s.** Change **Integration** to `widget`. Say: "If I only want embeds, seven surfaces survive." Set it back to Any. Change **Sort** to Reach. Say: "Same shortlist, biggest first."

**35 to 45s.** Type a product name, click **Copy playbook**. Say: "One Markdown file: shortlist table, five pitch angles, the KPI to negotiate, a 30-day plan. Paste it into Notion and start outreach on Monday. The URL carries the inputs, so I can send this exact map to a cofounder."

If asked how it is built: one HTML file, one JSON file, one scoring module with unit tests. No framework, no backend, no API calls. Reach bands are order-of-magnitude and dated; `verify` marks the ones I am not sure of.
